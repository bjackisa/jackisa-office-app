
## Oct 31 2026 — security hardening + licence/trial audit

### API auth audit (fixed)
The office app had **10 /api routes** reading/writing with the service-role
client and **no caller check**, plus a client-only feature gate. Fixed in commit
"fix(security): authenticate every data route, gate modules server-side".

New helpers:
- `lib/lic/serverAuth.ts`: `getSession()` (caller + raw bearer), `requireMember()`
  (any active member), alongside existing `getCaller/requireCompanyAdmin/requireSuperAdmin`.
- `lib/lic/guard.ts`: `requireFeature(req, companyId, slug)` — server-side mirror of
  the client `can()` gate (tier + company kind/override + role grant). Loads
  `platform_features` catalogue and registers it before checking.
- `lib/api.ts`: `apiFetch()` / `apiJson()` — attaches the Supabase access token.
  **Every client call to a data route must use this, not raw fetch.**

Routes now guarded: `lic/license` (admin for issue/renew/change, member for
status/validate/change-quote), `lic/payments` (admin initiate, member status/history),
`jackisa` (admin POST, member GET), `payments/initiate` (member, body userId ignored),
`payments/status` (member of the payment's company), `payments/webhook` (HMAC sig via
`PAYMENTS_WEBHOOK_SECRET` or lic peer sig), `trial` (member; start/status/cancel),
`kyc` (GET requires caller; auto_individual now binds badge to the caller and matches
the jackisa.com email), `education/notify` + `education/student` + `reports/income-tax*`
(feature-gated), `lic/sync` GET (lic sig or `CRON_SECRET`).

Key lesson: **never trust `userId`/`initiatedBy`/`companyId` from the request body.**
`kyc auto_individual` used to mint a blue badge for any user id supplied by the client.

### Licence / trial flow (verified live)
- Hub plans: basic/pro/platinum × {1,3,6,12,24,36}m — monthly→3y upfront all present.
- `LicenseService::startTrial` denies on fingerprint OR IP already seen (device+IP).
- `CronService`: `trials.remind` (2 days early, email+WhatsApp), `trials.expire`
  (auto-charges the msisdn via JPesa for the chosen `plan_code`), `licenses.expire`
  (grace window), `payments.reconcile`, `sync.pull`, `tax.snapshot`, `fund.snapshot`,
  `fund.daily`, `reminders.renewals`. `run-all` verified working.
- Plan memory: `lib/lic/planMemory.ts` (localStorage `jackisa:plan`) — written by
  `auth/register`, read+pre-selected by `settings/billing`, cleared once a non-trial
  licence is live. Survives the SSO/email-verify reload.

### Auth / join flow (fixed, later commits)
- **`/auth/join` POSTed with raw `fetch` (no bearer)**, so `request_join` always
  returned "Not signed in" — every invite link was dead on submit. Now uses
  `apiFetch`; also resumes a `pendingInvite` (localStorage) once the user
  confirms their email on another tab.
- `lib/auth/sso.ts`, `auth/register`, `auth/callback` also moved to `apiFetch`.
- `auth/register` skips the company step when `pendingRegistration` already has
  company details (SSO return path).
- New `/auth/find-company` page + `search_companies` action in
  `api/companies/members` — join a company with no invite link.
- **`company_employees.company_role_id` was NOT NULL** but the invite/join paths
  inserted with a null role → every request-to-join failed at insert. Fixed by
  `scripts/office-membership-and-trial-v2.sql` (drop NOT NULL, `jo_default_company_role()`,
  auto-create trigger, back-fill) + assigning the default role in the route.
- **`getMembership` ignored `status`** — a removed (inactive) member still passed
  every server guard. Now requires `status = 'active'`.
