## jackisa.com messaging pattern (the thing we mirrored)
- Every transactional email funnels through `PT_SendMessage()` in
  `assets/includes/functions_one.php`. Right after PHPMailer returns it calls
  `PT_WhatsAppHookEmail($data,$sent,$error)` (defined in
  `assets/includes/whatsapp.php`) which calls `PT_WhatsAppNotifyEmail()`.
- Provider chain in `assets/includes/whatsapp/module.php` `PT_WhatsAppSend()`:
  **Whapi.Cloud (primary)** -> Meta Cloud API -> Blueticks -> AiSensy. Whapi is
  primary because it drives a real linked WhatsApp account: plain text, images,
  documents, no template pre-approval.
- Whapi client `assets/includes/whatsapp/whapi.php` (`PT_WhapiClient`): base
  `https://gate.whapi.cloud/`, bearer token, `POST /messages/text` `{to,body}`.
- Body for WhatsApp is the HTML email **flattened** (`whatsapp/html_to_text.php`)
  then polished (`whatsapp/polish.php`). Email itself is untouched.
- Failures are swallowed+logged so they can never break email delivery.

## Peer-signature validation chain (office <-> lic) — verified live 2026-10-31
- Office signs each lic call in `lib/lic/client.ts` `sign()`:
  `X-Lic-Signature: sha256=<hex HMAC-SHA256(rawBody, LIC_OFFICE_SECRET)>`
  plus `X-Lic-Peer: office`.
- lic verifies in `src/Middleware/Auth.php::requirePeer()` ->
  `src/Support/Crypto.php::verifyPeer($peer,$raw,$sig)`, comparing against
  `config('peers.office.shared_secret')` and any `peers.office.shared_secrets[]`
  (rotation list). Not the `license.signing_secret` — that one only signs
  licence certificates (`Crypto::sign`).
- So the Vercel value must be **byte-identical** to the *deployed* lic
  `config/config.local.php` `peers.office.shared_secret`. Verified by live
  signed POST to /api/v1/office-license/status: correct secret -> 404
  "Unknown tenant" (auth passed), wrong secret -> 401.
- The deployed lic app lives at `~/domains/lic.jackisa.com/app` (web root is
  `public_html/` with a shim). `lic_cron.php` on jackisa shells to
  `<app>/bin/cron.php run-all`; office's Vercel cron calls `/api/cron/tick`
  which calls lic `/api/v1/cron/run`.
