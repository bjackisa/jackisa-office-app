## Coupons — root causes found
1. **Office sent a pre-discounted amount to the hub.** `billing/page.tsx`
   computed `due = base - coupon.discount` and passed `amount: due` plus
   `couponCode`. The hub applies the coupon to whatever amount arrives, so
   discounts were doubled. Fix: send `baseAmount` (`quote.amount_due` for a
   change, plan price otherwise).
2. **A 100% waiver sent `amount: 0`**, which the hub rejects before looking at
   the coupon. Fix: send the base and let the hub redeem it as free; the hub now
   validates `msisdn` only when the post-coupon amount is > 0.
3. **Plan matching was exact.** A coupon restricted to package `pro` did not
   match plan `pro_12m`. Fix: `CouponService::planAllowed()` accepts exact code
   or `<package>_` prefix; `intervalFromPlanCode()` parses `12m` / `-12m`.
4. **Legacy per-account cap 1** made "every payment" and multi-cycle coupons
   one-shot. Fix: `ineligibleReason()` treats `max_uses_per_tenant = 1` as
   unlimited unless duration is `once`; duration (`once`/`cycles N`/`forever`)
   governs. Migration 009 changes the default to 0.
5. **Partial discounts were never recorded** because `redeem()` only ran for
   free coupons. Fix: `CouponService::recordPayment()` called from
   `PaymentService::fulfill()`, idempotent on `payment_id`, increments
   `current_uses` and inserts the redemption.
6. **Admin console could not target accounts or packages properly.** Added
   `/api/admin/companies` (super-admin search by name/email or ids) and a
   searchable account picker + package/exact-plan chips in
   `app/app/admin/coupons/page.tsx`. Payload now includes
   `audience_tenant_ids`, `applies_plan_codes`, `applies_intervals`.

## Billing UI behaviour
- A typed/applied code now wins over the auto-apply quote (`appliedCode`).
- Switching plan/period re-validates an applied code and clears it with a
  readable reason if it no longer fits.
- Auto-apply quotes and manual validation both use the same `baseAmount`.
- A coupon-covered change no longer asks for a mobile-money number.
